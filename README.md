# Посмотри в окно

Учебная работа Яндекс Практикума: оформление готового приложения для поиска видео по городу и времени суток.

Репозиторий: https://github.com/shimoro3212/posmotri-v-okno-ad

Реализованы расположение блоков по макету, оформление видео и карточек, пользовательские чекбоксы, состояния наведения, нажатия и клавиатурного фокуса. Исходная логика приложения сохранена.

Для запуска откройте `index.html` в браузере. Для загрузки видео требуется подключение к интернету.
